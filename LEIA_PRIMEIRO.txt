ATIVIDADE CRUD CLIENTES - COMO TERMINAR E ENTREGAR

Este projeto segue os slides do professor: React + Vite, Node.js + Express e MySQL remoto.
O codigo essencial das quatro operacoes ja esta pronto no projeto.

ANTES DE COMECAR
- Use um computador Windows com Node.js 22.12+ instalado (https://nodejs.org/).
- Internet necessaria para baixar bibliotecas e se conectar ao MySQL remoto.
- Voce NAO precisa instalar MySQL nem criar banco no seu PC.
- O banco da turma e compartilhado. Edite e exclua apenas SEUS registros ficticios.

PASSO 1 - INSTALAR E COLOCAR SENHA
1. Extraia TODO o ZIP para uma pasta do computador.
2. Dê dois cliques no arquivo 1_INSTALAR_E_CONFIGURAR.bat.
3. Espere o npm terminar as instalacoes. Um Bloco de Notas abrira backend/.env.
4. Na linha BD_SENHA= cole a senha informada no slide 13 de Atividade_CRUD_Clientes.pdf.
5. Salve com Ctrl+S e feche o Bloco de Notas.
6. Se executar novamente, o script nao substitui sua senha.

PASSO 2 - ABRIR
1. Dê dois cliques em 2_ABRIR_SISTEMA.bat.
2. Deixe as DUAS janelas pretas abertas (API e React).
3. Abra http://localhost:5173 .
4. Se der erro de banco, confirme BD_SENHA e pergunte ao professor se seu IP esta liberado na Hostinger.

PASSO 3 - TESTAR E TIRAR OS 3 PRINTS
1. Cadastre 2 clientes de mentira com SEU NOME antes, ex.: SeuNome - Ana e SeuNome - Bruno. PRINT 1.
2. Clique Editar em um dos seus clientes, altere o telefone e salve. PRINT 2.
3. Clique Excluir no outro: primeiro Cancelar, depois Excluir e confirme. PRINT 3 da tabela apos excluir.
4. Aperte F5; confirme que o cliente restante continua no banco.
5. (Teste do roteiro): no Thunder Client, POST /clientes com e-mail invalido deve resultar status 400.

PASSO 4 - ENTREGAR NO TEAMS ate 13/11 23h59 (segundo o guia)
- Link de repositório do GitHub (opcao VS Code), ou link do CodeSandbox se adaptou o projeto.
- Tres prints: cadastro, edicao, lista apos exclusao.
- Respostas das 4 perguntas do slide 43. Ha sugestoes em RESPOSTAS_DAS_4_PERGUNTAS.txt.
- O roteiro tambem pede banco.sql, backend/, frontend/ e package-lock.json gerados pelo npm install.
- NAO publique backend/.env, a senha, node_modules/ nem dist/.
- O .gitignore ja esta configurado, mas VERIFIQUE antes de publicar.

COMO SUBIR PARA O GITHUB (VS CODE)
1. Abra a pasta extraida no VS Code.
2. Source Control > Publish to GitHub > Public repository.
3. Confirme no site que banco.sql, backend e frontend aparecem.
4. Confirme que backend/.env nao aparece, mas backend/.env.example aparece.
5. Copie o link do repositorio para a tarefa do Teams, anexe prints e respostas.

Se o professor pedir a entrega tambem em ZIP, compacte a pasta do projeto
SEM os node_modules, dist e backend/.env (e inclua os package-lock.json).

Observacoes:
- O desafio de adicionar campo cidade (slide 43) e opcional.
- Este ZIP NAO foi conectado ao banco remoto nem executado no navegador aqui.
- O setup npm install gera package-lock.json nas pastas backend e frontend.
